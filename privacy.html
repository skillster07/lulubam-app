1. 이 앱은 무엇인가요

「룰루밤 업로더」는 유튜브 채널 「룰루밤」 운영자가 자기 채널을 관리하려고 쓰는 개인용 도구입니다. 일반 사용자에게 제공하지 않으며, 운영자 본인의 Google 계정으로만 로그인합니다.

2. 어떤 정보에 접근하나요

  • 운영자 채널의 기본 정보(채널 ID·이름) — 올바른 채널에 올리는지 확인하는 데 씁니다.
  • 운영자 채널의 영상·재생목록 — 영상 업로드, 썸네일·자막·설명 설정, 재생목록 정리에 씁니다.
  • 운영자 채널의 통계(조회수 등) — 운영자가 성과를 확인하는 데 씁니다.

3. 아동 시청자

「룰루밤」은 아동용으로 설정된 채널입니다. 이 앱은 시청자(아동 포함)의 개인정보를 수집하지 않고, 시청자 댓글을 읽거나 모으지 않습니다.

4. 정보는 어떻게 보관하나요

Google 로그인으로 받은 인증 토큰은 운영자 컴퓨터에만 저장됩니다. 다른 서버로 보내지 않고, 다른 사람과 공유하거나 판매하지 않으며, 광고에 쓰지 않습니다.

5. 접근 권한 해제

Google 계정의 서드파티 앱 및 서비스 페이지에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다. 해제하면 운영자 컴퓨터의 토큰도 더 이상 쓸 수 없습니다.

6. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 쓰고 다른 앱으로 넘기는 방식은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요건을 따릅니다. 이 앱은 YouTube 서비스 약관과 Google 개인정보처리방침을 함께 따릅니다.
